\section{Постановка задачи}
% ═════════════════════════════════════════════════════════════

Рассматривается задача безусловной минимизации
\[
    \min_{x \in \R^n} f(x),
\]
где $f$ --- дифференцируемая функция.

В работе реализованы и исследованы шесть модификаций градиентного спуска:
\begin{enumerate}
    \item Momentum;
    \item Nesterov;
    \item AdaGrad;
    \item RMSProp;
    \item AdaDelta;
    \item Adam.
\end{enumerate}

Тестовые задачи:
\begin{itemize}
    \item хорошо обусловленная выпуклая квадратичная функция;
    \item плохо обусловленная выпуклая квадратичная функция;
    \item функции Розенброка, Экли и Химмельблау.
\end{itemize}

Во всех экспериментах использована фиксированная точность
\[
    \norm{\grad f(x_k)} < \eps, \qquad \eps = 10^{-8}.
\]

% ═════════════════════════════════════════════════════════════
\section{Описание методов}
% ═════════════════════════════════════════════════════════════

\subsection{Momentum}
\[
v_{k+1} = \beta v_k + \grad f(x_k), \qquad
x_{k+1} = x_k - \alpha v_{k+1}.
\]
Параметры: шаг $\alpha > 0$, коэффициент инерции $\beta \in (0,1)$.

\subsection{Nesterov}
\[
\tilde{x}_k = x_k - \beta v_k,\quad
v_{k+1} = \beta v_k + \alpha \grad f(\tilde{x}_k),\quad
x_{k+1} = x_k - v_{k+1}.
\]
Градиент берётся в точке ``заглядывания'' $\tilde{x}_k$.

\subsection{AdaGrad}
\[
G_{k+1} = G_k + (\grad f(x_k))^2,\qquad
x_{k+1} = x_k - \alpha \frac{\grad f(x_k)}{\sqrt{G_{k+1}} + \delta}.
\]
Параметр: начальный шаг $\alpha$, стабилизатор $\delta$.

\subsection{RMSProp}
\[
S_{k+1} = \rho S_k + (1-\rho)(\grad f(x_k))^2,\qquad
x_{k+1} = x_k - \alpha \frac{\grad f(x_k)}{\sqrt{S_{k+1}} + \delta}.
\]
Параметры: $\alpha$, коэффициент сглаживания $\rho$.

\subsection{AdaDelta}
\[
E[g^2]_{k+1} = \rho E[g^2]_k + (1-\rho)g_k^2,
\]
\[
\Delta x_k = -\frac{\sqrt{E[\Delta x^2]_k+\delta}}{\sqrt{E[g^2]_{k+1}+\delta}}\,g_k,\qquad
x_{k+1}=x_k+\Delta x_k.
\]
В базовой форме отдельный learning rate не используется.

\subsection{Adam}
\[
m_{k+1}=\beta_1m_k+(1-\beta_1)g_k,\qquad
v_{k+1}=\beta_2v_k+(1-\beta_2)g_k^2,
\]
\[
\hat m_{k+1}=\frac{m_{k+1}}{1-\beta_1^{k+1}},\qquad
\hat v_{k+1}=\frac{v_{k+1}}{1-\beta_2^{k+1}},
\]
\[
x_{k+1}=x_k-\alpha\frac{\hat m_{k+1}}{\sqrt{\hat v_{k+1}}+\delta}.
\]
Параметры: $\alpha$, $\beta_1$, $\beta_2$.

\section{Общие выводы}
% ═════════════════════════════════════════════════════════════

\begin{enumerate}
    \item Для квадратичных задач все методы дают сходимость при корректной настройке параметров, но чувствительность к параметрам у методов существенно различается.
    \item На функции Розенброка наиболее устойчивыми в текущих сетках оказались Momentum и Adam; RMSProp и AdaDelta потребовали бы дополнительного подбора.
    \item На многоэкстремальных функциях (Экли, Химмельблау) итог зависит от стартовой точки и настроек, что подтверждается различием траекторий.
    \item Формат экспериментов ``таблицы + line/heatmap + траектории'' обеспечивает прямое соответствие требованиям задания лабораторной.
\end{enumerate}
